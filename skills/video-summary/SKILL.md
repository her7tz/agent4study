# 视频知识总结

## 目标

让读者用更少时间准确理解核心内容，看清知识之间的关系，并方便查阅和复习。
以内容、知识和问题为中心组织笔记。当前阶段的 JSON 字段与调用协议由 Harness 提供。

## 知识组织

- 每个段落围绕一个概念、问题、原理或方法展开，标题直接表达知识主题。
- 相关内容可以跨视频位置合并，按照理解所需的顺序排列，不机械遵循讲述顺序或均匀时间切片。
- 保留关键的“是什么”“为什么”“如何做”，以及适用条件、例外和必要推理。
- 根据重要程度分配篇幅，压缩重复表达、闲聊和次要故事；保留确实帮助理解的例子。
- 课程讲座适合概念、原理、推导、例子和适用条件；操作教程适合目标、准备、步骤、结果和常见问题；观点访谈适合主张、理由、证据与限制；问答视频按问题主题归类。

## 内容准确性

- 只使用输入材料支持的内容，不补写未经提供的事实、因果关系或结论。
- 保留影响理解的条件和例外，不能把有限结论扩大为普遍规律。
- 对观点、建议与模型推断说明性质和依据。必要时用“视频中的观点”或“该建议”等表达，避免把个人判断写成已核实的知识。
- 对转录错误、模糊术语和无法确认的信息标记不确定性，不根据猜测强行纠正。
- 聚焦内容本身，不介绍讲述者的衣着、外貌、动作、表情和无关背景。

## 开头与视觉辅助

- 开头可以提供简短概述，说明主题、核心问题和主要结论，避免逐项复述全文目录。
- 内容有清晰整体结构时，可以在开头加入框架图或流程图；没有合适结构时省略。
- 在对应知识附近放置图示，不为每段强制配图，也不设固定图示数量。
- 少量小图标可用于提示概念、例子、步骤或注意事项，不能替代知识说明，也不要在每个标题重复装饰。
- 概念图解释概念的层次与联系；流程图解释真实步骤、分支、反馈或材料支持的因果关系。避免把无关观点连接成因果链。
- 视频原图用于公式、代码、图表、实验结果、操作界面或重要原始问题，不为了展示讲述者而配图。
- 文字分析阶段仅提出候选画面位置和需要核对的知识内容，不断言尚未看到的画面。
- 画面分析阶段判断原图是否确实增加知识价值。说明只围绕可见且相关的内容，不描述讲述者衣着动作、无关文件名、界面装饰或背景。
- 无知识价值、无法辨认或与相关内容不符的画面应省略。看不清的文字不能作为精确引文、数字或公式。

## 时间信息

- 成品概述、标题、正文、图示、图片说明和图片替代文本都不显示时间戳或时间范围。
- Harness 提供的秒数和来源位置仅供内部定位文字、合并知识与提取原图；按调用协议保留这些内部字段。
- 时间作为知识本身时可正常表达，例如算法耗时、实验持续时间或历史事件日期；不展示视频播放位置。

## 提交前检查

检查核心内容是否遗漏、知识分组是否合理、结论是否有依据、必要逻辑和条件是否保留、图示是否增加理解价值，以及成品是否包含无关人物描述或视频时间标记。

# Study Log 连接

在 Agent 设置中点击“连接 Study Log”，授权页面会自动打开。用现有 ChatGPT 账号登录、核对连接码并确认只读授权；若浏览器阻止弹窗，可点击“重新打开授权页面”。回到 Agent 后连接自动完成，也可点击“检查连接”。连接请求需在 10 分钟内确认，授权有效期 30 天，过期后重新连接。

如果检查连接时遇到网络错误，工作台保留最近一次确认的状态和取消入口。连接码到达预计时限后，仍以网站返回的状态为准。网络恢复后自动检查，超过重试次数时可点击“检查连接”。

连接后开启“允许联网查询”，可在主 Agent 对话中说“分析本周学习进度”“根据 Study Log 写一份上周周报”或“整理 2026-10-01 至 2026-10-15 的学习情况”。`read_study_log` 工具读取记录、项目、统计；日期筛选含首尾两天，记录按 `next_offset` 分页，不把第一页当成全部。分析所需内容会提交给主 Agent 当前配置的模型服务。

## 周报与日期范围复盘

`create_study_report` 提交后台 `study_report` 工作流，复用共享执行池、取消、进度和成果回传。任务完成后，一份报告自动保存到内容库的“学习周报”分类，默认目录为 `summaries/study_report/`，可以打开、删除或恢复；无需再点下载或调用通用保存工具。

- 本周：Asia/Shanghai 本周一至生成当天；上周：上一个完整自然周；自定义：起止日期均包含，最多 90 天，可按项目编号筛选。
- 先读取完整分页，再由程序计算记录数、活跃天数、学习与实验各自的强度、日期分布、项目分布和积分。积分依据当前项目重要度；强度和积分不代表耗时或知识掌握程度。
- 学习内容复用 `SummaryEngine` 进行知识提取、全文整合和来源编号检查，再结合项目当前目标与状态提出复盘建议。每个知识主题保留记录编号、日期和项目依据。
- 项目和实验当前累计计数属于读取时快照，不能用于推断本期新增完成量。报告不会自动写入个人知识库。
- 每次最多 5000 条记录、项目与记录合计 30 万字符。全程使用开始读取时的授权，复查每页记录和项目。超限、分页不完整、授权或材料变化时停止生成。接口没有事务快照，复查仍无法排除所有并发更新。
- 没有记录时生成实际的零记录报告，不编造学习成果。

定时任务页面可选择“Study Log 学习周报”，也可通过对话安排单次或每日执行。相对的本周／上周在每次执行时重新计算；自定义日期范围保持固定。执行依赖本地电脑、服务、网络和有效授权；关机或睡眠时错过的任务继续沿用跳过并记录的策略。当前调度支持单次和每日，尚未增加每周重复规则。

Study Log 的“Agent 只读授权”页面可随时撤销。Agent 设置中的“撤销并断开”也会撤销服务器授权。网络不可用或网关响应无法确认授权状态时保留本地连接信息，以便重试。工作台确认断开或检查到授权变化后，丢弃此前读取请求的迟到响应。已生成的聊天和报告继续保存在本机。

周报在每次模型调用和保存前查询原授权状态。授权已撤销、过期或暂时无法确认时，本次任务停止，原因可在运行记录查看；已经发出的模型请求可能仍会返回。连接恢复后可重新提交报告。

## 维护

- `study_log.py`：独立连接与读取适配器；主 Agent 在 `conversation.py` 中注册只读工具。
- `study_report.py`：范围校验、完整分页、确定性统计、共享总结与独立分类保存。
- `skills/study-review/SKILL.md`：学习复盘规则，可在 Agent 设置中编辑主 Agent 的私有覆盖；与共享 `summary-core` 一起使用。
- `capabilities.py`：`study_report` 声明 `settings_role="conversation"`，由主 Agent 拥有，支持通用后台与调度，不产生新的 Subagent。
- `web_server.py`：在现有本地来源检查及 CSRF 防护下提供连接操作；本地 UI 不接收访问凭证。
- `web/study_log.js`：连接状态、批准链接、撤销入口。
- 凭证保存在数据目录 `connections/study-log.json`，目录权限 0700、文件权限 0600；不进入 Git、聊天或工具结果。网站只存凭证摘要。连接固定到 Study Log 地址，网络请求拒绝重定向，避免凭证转发。
- 无 ChatGPT 密码读取、Cookie 复制或浏览器会话转移。实际批准由用户在网站完成。
- 隔离环境覆盖待授权拒读、账号隔离、两端撤销和失败后重试。部署环境中，用户已批准一条临时连接。记录、项目和统计均可读取，撤销后三个接口均拒绝原凭证。见[真实只读授权验收](实施与验收记录.md#136-study-log-部署站点真实只读授权2026-11-17)。 [隔离配对验收](acceptance/2026-11-09-study-log-pairing.json) · [部署验收](acceptance/2026-11-16-study-log-deployed-pending.json)

此能力归主 Agent 所有，复用已有对话与报告保存工具，不增加业务 Subagent。测试可给适配器传入本机 HTTP 地址；产品界面不允许模型或网页替换服务器地址。
